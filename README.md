# کانون‌ها — اپ مستقل دانشجویی

**نسخه آزمایشی:** 0.4.0-online-preview — Android 8.0+ (API 26).

این مخزن صرفاً مربوط به اپ مستقل «کانون‌ها» است و هیچ وابستگی اجرایی یا دارایی بصری به اپ «همراه» ندارد.

## صفحات
خانه، کانون‌ها، رویدادها، فعالیت‌های من، حساب کاربری.

رابط آفلاین با HTML/CSS/JavaScript در `app/src/main/assets` است؛ پوسته اندروید از `WebViewAssetLoader` استفاده می‌کند. نام، نشان برنامه، داده‌های نمونه و وضعیت ثبت‌نام آزمایشی از سرویس‌های واقعی تفکیک شده‌اند.

## دامنه نسخه
- مرور کانون‌ها و رویدادهای **نمونه**، جستجو و فیلتر.
- عضویت و ثبت‌نام **آزمایشی محلی**، ذخیره در `localStorage`، بازنشانی و نمایش بلیت **فاقد اعتبار**.
- رفتن میان پنج صفحه، بازگشت اندروید به خانه و بسته‌شدن پنجره جزئیات با دکمه بازگشت.
- **فاقد** حساب واقعی، تأیید هویت، سرور، ظرفیت لحظه‌ای، ثبت‌نام رسمی، QR قابل اسکن، پرداخت و بلیت معتبر.

اطلاعات دانشجویی و فهرست رویدادها واقعی نیستند. داده‌های آزمایشی به سرور ارسال نمی‌شوند. در نسخه جدید فهرست عضویت و رویدادهای ثبت‌شده به طور پیش‌فرض خالی است.

## آزمایش و ساخت
- آزمون مستقل از وابستگی خارجی: `node tests/ui-smoke.cjs`.
- بررسی نحوی JavaScript: `node --check app/src/main/assets/app.js`.
- ساخت با **JDK 17، Android SDK 35 و Gradle 8.9**: `gradle :app:assembleDebug --no-daemon`.
- GitHub Actions در `.github/workflows/android.yml` در Push و Pull Request، آزمون‌ها را اجرا و APK نسخه Debug را به‌عنوان Artifact منتشر می‌کند.

نسخه آزمایشی Debug برای بررسی است؛ انتشار Production و ورود اطلاعات واقعی فقط پس از تکمیل بک‌اند، احراز هویت، امنیت و آزمون دستگاه مجاز است.

## نسخه آنلاین ۰.۴.۰
فایل‌های `app/src/main/assets/backend.js` و `config.js` اتصال اختیاری حساب کاربری ایمیلی به Supabase مستقل را فراهم می‌کنند.
طرح SQL و راهنمای راه‌اندازی در [supabase/SETUP_FA.md](supabase/SETUP_FA.md) هستند.
**به‌صورت پیش‌فرض اتصال خاموش است**؛ تا زمان ایجاد پایگاه داده اختصاصی و واردکردن publishable key، همه چیز نمایشی آفلاین می‌ماند.
در حالت آنلاین فهرست کانون‌ها و رویدادها از سرور خوانده می‌شود، پروفایل دانشجو ذخیره می‌شود، درخواست عضویت ثبت می‌شود، ثبت‌نام رویداد در سرور انجام می‌شود و فعالیت‌ها بازخوانی می‌شوند.
شماره دانشجویی هنوز اعتبارسنجی دانشگاهی ندارد؛ ثبت‌نام رویداد فقط ظرفیت را رزرو می‌کند و بلیت معتبر صادر نمی‌کند.
تست‌های افزوده: `node tests/backend-smoke.cjs` و `node tests/online-ui-smoke.cjs` (شبیه‌سازی API؛ **نه** آزمون پایگاه داده واقعی).
