# گزارش کنترل کیفیت مرکز اطلاع‌رسانی کانون‌ها

تاریخ: ۲۰۲۶-۱۱-۱۱ | محدوده: پروژه مستقل Kanonyar-Arak | نسخه هدف: ۰.۹.۲۵ بتا

## پیاده‌سازی
- Migration: supabase/notifications-v022.sql؛ اعمال موفق به دیتابیس اختصاصی Kanonha.
- Edge Function: kanonha-admin-console نسخه ۹؛ verify_jwt=true، تأیید مدیرکل با ایمیل تأییدشده و مجوز پایگاه داده.
- مدیرکل: ساخت کمپین رویداد/کانون/آپدیت/عمومی، گیرندگان کل/دانشجویان/دبیران/دانشگاه/چند دانشکده/اعضای کانون، شمارش گیرندگان، تأیید دومرحله‌ای و تاریخچه.
- دانشجو: صندوق اعلان با وضعیت خوانده‌شده، نمایش عکس معتبر، مسیر مستقیم به رویداد یا کانون، استعلام‌گیری هنگام ورود و بازگشت به برنامه.
- نسخه اندروید: versionCode=40 و versionName=0.9.25-notifications، بدون تغییر applicationId.

## آزمون‌های واقعی انجام‌شده
۱. شمارش نقش‌ها: all=1، students=1، secretaries=1؛ دانشگاه/دانشکده غیرواقعی=0 (پایگاه داده عملیاتی کم‌تعداد).
۲. SQL تراکنشی: انتشار سراسری و شمارش سطرها موفق؛ تمام تغییرات آزمایشی بازگردانی شد.
۳. جلوگیری از ارسال تکراری: درخواست یکسان دو بار، فقط یک کمپین و یک تحویل؛ بازگردانی موفق.
۴. SQL مجوزها: authenticated قابلیت INSERT کمپین، DELETE تحویل یا اجرای publish ندارد؛ فقط SELECT مجاز خود و UPDATE ستون read_at؛ anon نمی‌تواند preview بزند.
۵. ممیزی Supabase: توابع جدید نشر/پیش‌نمایش در هشدارهای دسترسی signed-in دیده نشدند. هشدارهای قدیمی سرویس‌های دیگر خارج از محدوده این تغییر باقی هستند.
۶. GitHub Actions: syntax check فایل‌های JS، Deno type check تابع مدیریتی و smoke اعلان‌ها در اجرای PR موفق شدند؛ build APK در اجرای PR نسخه پیش از افزایش versionCode نیز موفق ثبت شد.
۷. تصویر رویداد/لوگو و نسخه ۴۰ بعد از اجرای موفق قبلی تغییر کرده‌اند و برای اعلام قبولی نهایی باید اجرای CI آخرین SHA بررسی شود.

## معیارهای عملیاتی و موانع
- اعلان‌ها هنگام حضور/بازگشت کاربر به اپ خوانده می‌شوند؛ Push در پس‌زمینه/برنامه بسته اجرا نشده است.
- برای FCM لازم است Firebase Android app رسمی با package ثابت، google-services.json، سرویس محرمانه برای ارسال پیام FCM، ثبت توکن دستگاه و تست مجوز نوتیفیکیشن روی گوشی فراهم شوند.
- نسخه debug از package مستقل .test استفاده می‌کند؛ نسخه release بدون امضای پروژه قابل نصب به‌عنوان به‌روزرسانی اپ موجود نیست.
- سناریوی دو کاربر واقعی در دو دانشکده متفاوت روی دستگاه هنوز تست نشده است.
- هیچ پیام واقعی توسط تیم توسعه به کاربران ارسال نشده است.
